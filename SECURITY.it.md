# Sicurezza

[English](SECURITY.en.md) · **Italiano**

Segnalare privatamente le vulnerabilità a **braket71@gmail.com**, indicando versione,
impatto e procedura minima di riproduzione. Non includere credenziali reali o dati personali.
La ricezione viene confermata, quando possibile, entro 5 giorni lavorativi.

Sono supportate l'ultima release e il ramo `main`. Le correzioni critiche saranno pubblicate
con release e nota di sicurezza. Cambiare immediatamente credenziali eventualmente esposte.
