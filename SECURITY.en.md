# Security

**English** · [Italiano](SECURITY.it.md)

Report vulnerabilities privately to **braket71@gmail.com**. Include the affected version,
impact, and a minimal reproduction procedure, but never send real credentials or personal
data. Receipt will be acknowledged within five business days whenever possible.

The latest release and the `main` branch are supported. Critical fixes will be published as a
release with a security notice. Rotate any credential that may have been exposed immediately.
