Authentication behavior

Local authentication always remains enabled for recovery. LDAP passwords are verified directly against LDAP and are never stored. LDAP users receive a local shadow profile for role and optional TOTP MFA. OIDC/SSO users receive a shadow profile for role; MFA is normally enforced by the Identity Provider.
